# Tenka Musō

**Live App:** https://tenkamuso.netlify.app

---

## Ελληνικά

Το **Tenka Musō** είναι μια προσωπική εφαρμογή οργάνωσης, παραγωγικότητας και ημερολογίου. Στόχος της είναι να βοηθά τον χρήστη να οργανώνει την ημέρα του, να καταγράφει εργασίες, συνήθειες, σημειώσεις, στόχους, projects και ιδέες για αργότερα.

Η εφαρμογή δουλεύει και σε κινητό, με responsive περιβάλλον και Progressive Web App υποστήριξη, ώστε να μπορεί να χρησιμοποιηθεί σαν mobile-friendly web app.

### Τι προσφέρει

- Ημερήσια, εβδομαδιαία και μηνιαία προβολή εργασιών.
- Δημιουργία, επεξεργασία και ολοκλήρωση tasks.
- Καταγραφή χρόνου με ώρα έναρξης και λήξης.
- Daily notes / προσωπικό ημερολόγιο ανά ημέρα.
- Backlog για ιδέες και μελλοντικές εργασίες.
- Custom κατηγορίες.
- Αναζήτηση σε tasks και σημειώσεις.
- Στατιστικά χρόνου και δραστηριότητας.
- Goals για εβδομαδιαίους ή μηνιαίους στόχους.
- Projects με project mentions, linked tasks και milestones.
- Backup export και safe backup import από JSON.
- Anonymous, Google και email/password authentication.
- Password reset μέσω Firebase.
- Real-time συγχρονισμό δεδομένων μέσω Firestore.
- Mobile-friendly χρήση και PWA υποστήριξη.

### Τεχνολογίες

- **React** για το user interface.
- **TypeScript** για typed frontend development.
- **Vite** για γρήγορο development και production build.
- **Tailwind CSS** για styling.
- **Firebase Authentication** για anonymous, Google και email/password login.
- **Cloud Firestore** για αποθήκευση και real-time συγχρονισμό δεδομένων.
- **Netlify** για deployment.
- **Progressive Web App** manifest και service worker για mobile-friendly εμπειρία.

## English

**Tenka Musō** is a personal productivity, organization and journaling web application. Its goal is to help users structure their day, track tasks, habits, notes, goals, projects and future ideas.

The application works on mobile devices through a responsive interface and Progressive Web App support, making it usable as a mobile-friendly web app.

### What it offers

- Daily, weekly and monthly task views.
- Task creation, editing and completion tracking.
- Time tracking with start and end times.
- Daily notes / personal journal entries.
- Backlog for future ideas and unscheduled work.
- Custom categories.
- Search across tasks and notes.
- Time and activity statistics.
- Weekly and monthly goals.
- Projects with project mentions, linked tasks and milestones.
- Backup export and safe JSON backup import.
- Anonymous, Google and email/password authentication.
- Password reset through Firebase.
- Real-time data synchronization through Firestore.
- Mobile-friendly usage and PWA support.

### Technologies

- **React** for the user interface.
- **TypeScript** for typed frontend development.
- **Vite** for fast development and production builds.
- **Tailwind CSS** for styling.
- **Firebase Authentication** for anonymous, Google and email/password login.
- **Cloud Firestore** for data storage and real-time synchronization.
- **Netlify** for deployment.
- **Progressive Web App** manifest and service worker for a mobile-friendly experience.
